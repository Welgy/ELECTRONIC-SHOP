# ELECTRONIC-SHOP

Современная витрина электроники, созданная с нуля на чистых веб-технологиях.

## 🚀 Демо
Посмотреть работающий сайт можно здесь: [ELECTRONIC-SHOP](https://welgy.github.io/ELECTRONIC-SHOP/)

## 🛠 Технологии
*   **HTML5** — семантическая верстка
*   **CSS3** — адаптивный дизайн, Flexbox, Grid
*   **JavaScript (Vanilla)** — логика фильтрации, поиска и корзины

## 📦 Функционал
- [x] Каталог товаров с карточками
- [x] Фильтрация по категориям, цвету и памяти
- [x] Живой поиск по названию
- [x] Корзина (сохранение в `localStorage`)
- [x] Избранное (сохранение в `localStorage`)
- [x] Страницы товаров с характеристиками
